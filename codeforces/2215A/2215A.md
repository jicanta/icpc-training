## Interval mod
Link: https://codeforces.com/contest/2215/problem/A

It's obvious that the only two operations we'll be interested in doing are $a_i=a_i mod p$ or $a_i=a_i mod q mod p$ (assuming $p < q$).
But because of the interval length restriction in which we can apply operations, we can't just take the minimum of both for each element. However, once we fix the first interval in which we apply any of the two aforementioned operations, we can just take for each remaining element $min(a_i mod p, a_i mod q mod p)$.
Then, we can easily solve it with prefix sums.
The intuition that the restriction falls in the first interval is the following:
The first intervall will be the only one that cannot be "customized".
Before doing anything, every operation must affect a block of length at least $k$. So the very first operation necessarily hits some whole interval.
Once this first interval is fixed, I can use it to customize the remaining elements.
The first operation defines a region, and after that, I can use it to freely determine the final value of the other elements.
